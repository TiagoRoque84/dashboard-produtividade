# Dashboard de Produtividade

Este repositório é estático e já está pronto para rodar no **GitHub Pages**.

## Como publicar no GitHub Pages

1. Suba este repositório para o GitHub.
2. Vá em **Settings → Pages**.
3. Em **Build and deployment**, selecione:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (ou a branch padrão)
   - **Folder:** `/ (root)`
4. Salve e aguarde o deploy (normalmente 1–3 minutos).

## Link de acesso

Depois de publicar, o link fica neste formato:

`https://<seu-usuario>.github.io/<nome-do-repositorio>/`

A raiz do site abre `index.html`, que redireciona automaticamente para `dashboard_html.html`.
